> 一行命令，安装任意技能

所有技能托管在同一个仓库，用 npx skills 按需安装单个；安装后 Agent 会在新会话根据 SKILL.md 的名称与描述自动匹配触发。

install — zsh

$ npx skills add …

把 <skill> 换成下方任意技能名。

$ npx skills add tjxj/z-skills --skill z-grounded-source-qa
  • #安装位置由 Skills 环境决定（如 .agent/skills/），无需手动配置。
  • #一次装全部：cp -R z-* /path/to/.agent/skills/
  • #触发靠每个 SKILL.md 的 name 与 description，触发词越准命中越稳。

> 为什么是 Skills

把可复用的工作流沉淀成稳定能力，而不是每次临时提示。

◆ 触发词清晰

每个 SKILL.md 用明确的 name 与 description 声明触发场景，命中即接管，减少反复解释。

◆ 流程可执行

能脚本化的都沉淀为 scripts/，优先调用脚本，避免手工重复与不一致。

◆ 输出可验证

生成结果尽量做一次实际查看或运行校验，带退出码的验证脚本才算完成。
