一行命令，安装任意技能

所有技能都托管在同一个仓库，用 npx skills 按需安装单个，安装后 Agent 会在新会话根据 SKILL.md 的名称与描述自动匹配触发。

安装单个技能

把 <skill> 换成下方任意技能名即可。

$ npx skills add tjxj/z-skills --skill z-grounded-source-qa
  • ◆安装位置由你的 Skills 环境决定（如 .agent/skills/），无需手动配置。
  • ◆想一次装全部：cp -R z-* /path/to/.agent/skills/
  • ◆触发完全靠每个 SKILL.md 的 name 与 description，触发词越准命中越稳。

使用流程

1
安装技能用 npx skills 安装需要的技能到本地 skills 目录。
2
开启新会话Agent 自动读取 SKILL.md，注册技能与触发词。
3
自然语言触发说出触发词，技能接管对应工作流并产出结果。

为什么是 Skills

把可复用的工作流沉淀成稳定能力，而不是每次临时提示。

🧩

触发词清晰

每个 SKILL.md 都用明确的 name 与 description 声明触发场景，命中即接管，减少反复解释。

⚙️

流程可执行

能脚本化的都沉淀为 scripts/，优先调用脚本，避免手工重复操作与不一致。

✅

输出可验证

生成结果尽量做一次实际查看或运行校验，带退出码的验证脚本才算真正完成。
