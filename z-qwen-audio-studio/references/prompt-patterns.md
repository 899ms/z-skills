# Prompt patterns

`qwen-audio-3.1-tts-next` 接收完整的音频场景描述。明确任务、人物、台词、表达方式、环境声和时间顺序；角色称呼保持一致。

## Narration

```text
创作一段 20 秒中文科技解说。年轻男声，吐字清楚，语速中等。
他说：“AI 正在把一个人的创作能力，扩展成一支完整团队。”
录音室环境安静，结尾停顿半秒。
```

## Advertisement

```text
创作一段 15 秒产品广告。开头是一声清脆的开门声，随后明亮女声说：
“推开门，让灵感立即发生。”
台词下方有轻盈电子音乐，保持人声清晰；结尾音乐快速淡出。
```

## Podcast

```text
创作一段雨夜书房双人播客。窗外持续轻雨，室内声场温暖、距离稳定。
主持人使用沉稳男声说：“今天我们聊聊 AI 如何改变内容创作。”
嘉宾使用明亮女声回答：“最大的变化，是一个人也能完成整支制作。”
两人自然停顿，结尾雨声轻微渐弱。
```

## Drama with reference audio

```text
创作一段悬疑广播剧。@voice1 是侦探，@voice2 是店主。
门外脚步声由远及近，木门打开。
@voice1 压低声音说：“昨晚十点，你在哪里？”
玻璃杯轻轻碰到桌面后，@voice2 紧张地回答：“我一直守在店里。”
保持两位角色的音色稳定，房间混响较短。
```

## Constraints

- 模型当前支持中文和英文。
- Prompt 最多 3000 字符。
- 最多引用 `@voice1`、`@voice2`、`@voice3`。
- 每条参考音频最长 30 秒、最大 10 MB，格式为 WAV、MP3 或 OGG Opus。
- 参考音频编号与 `--reference-audio` 参数顺序一致。
